        What is QRIS?
        

          
QRIS (Quick Response Code Indonesian Standard) is Indonesia's national QR payment
          standard, published by Bank Indonesia. Every QRIS code is an EMVCo Merchant-Presented QR Code —
          a plain-text string of data objects. It is not encrypted, which is exactly why a decoder like this
          can read every field inside it.

        

      


      

        How TLV encoding works
        

          
Every data object has three parts: a 2-digit Tag, a 2-digit Length,
          then a Value of exactly that many characters.

          
59 12 TOKO MAKMUR → tag 59 (merchant name), length 12,
          value "TOKO MAKMUR". A full QRIS payload is just these objects placed back to back.

          
Some tags (26–51 and 62, 64) contain nested TLV inside their value — that's why this
          tool expands them into sub-tables.

        

      


      

        Static vs Dynamic codes
        

          
Static — tag 01 = 11. A reusable sticker; the payer types
          the amount. No tag 54.

          
Dynamic — tag 01 = 12. Generated per transaction, usually
          carries tag 54 (amount) and often expires after a short time.

        

      


      

        The CRC-16 checksum
        

          
The final object is always tag 63 with length 04. Its value is a
          CRC-16/CCITT-FALSE checksum computed over the entire payload including the literal
          characters 6304, using polynomial 0x1021 and initial value 0xFFFF.

          
If it doesn't match, the code has been corrupted, cropped, or manually edited.

        

      


      

        Tag cheat sheet
        

          
00 format · 01 static/dynamic · 26–51 merchant account
          templates · 52 MCC · 53 currency · 54 amount ·
          55–57 tip / fees · 58 country · 59 merchant name ·
          60 city · 61 postal code · 62 additional data ·
          63 CRC · 64 alternate-language info.

        

      


      

        Privacy & safety
        

          
Your image never leaves the device. Scanning happens locally via the jsQR library and
          parsing is plain JavaScript — no server, no uploads, no analytics.

          
⚠️ Decoded QRIS payloads can contain merchant IDs, store labels and reference numbers.
          Treat screenshots of them as sensitive.
